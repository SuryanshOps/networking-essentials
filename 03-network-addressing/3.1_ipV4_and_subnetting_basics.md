## 1. IPv4 Structure: The 32-Bit Map

An IPv4 address is the logical identifier assigned to every device on a network. While humans read it as four simple numbers separated by dots (e.g., `192.168.1.50`), computers read it as raw binary. 

An IPv4 address is exactly **32 bits long**, divided into four chunks of 8 bits called **Octets**.

    ┌────────────────────────────────────────────────────────┐
    │                HUMAN READABLE (DECIMAL)                │
    │            192   .   168   .    1    .    50           │
    ├────────────────────────────────────────────────────────┤
    │                 COMPUTER LOGIC (BINARY)                │
    │         11000000 . 10101000 . 00000001 . 00110010      │
    │         | 8 bits | | 8 bits | | 8 bits | | 8 bits |    │
    └────────────────────────────────────────────────────────┘

Every IP address actually contains two hidden pieces of information inside it:
1.  **The Network ID:** Like a ZIP code (identifies your entire neighborhood).
2.  **The Host ID:** Like your house number (identifies your specific PC in that neighborhood).

<br>

## 2. Public vs. Private IP Addresses

In the early days of the internet, engineers realized that 4.3 billion IPv4 addresses wouldn't be enough for every device in the world. To save addresses, they split IPs into two categories: **Public** and **Private**.

### 🌍 Public IPs (The External Phone Number)
*   Must be purchased/leased from your ISP.
*   Are 100% unique globally—no two devices on the internet can share the same Public IP.
*   Routable across the entire open internet.

### 🏢 Private IPs (The Internal Office Extension)
*   100% free. Anyone can use them inside their own home or enterprise network.
*   **Not routable** on the internet. If a private IP tries to talk to the open internet, the router drops it unless it is translated via NAT (Network Address Translation).
*   Defined by **RFC 1918**, there are three designated private blocks:

| Class | Private IP Range | Typical Use Case |
| :--- | :--- | :--- |
| **Class A** | `10.0.0.0` – `10.255.255.255` | Massive Enterprise Networks (Millions of hosts) |
| **Class B** | `172.16.0.0` – `172.31.255.255` | Medium/Large Corporate Networks |
| **Class C** | `192.168.0.0` – `192.168.255.255` | Small Business & Home Networks |

*(If you check your PC right now, your IP is almost certainly a Class C `192.168.x.x` address!)*

<br>

## 3. Subnet Masking: Drawing the Boundary

If an IP address is just a string of 32 bits, how does the computer know where the "Network ZIP Code" ends and the "Host House Number" begins? 

It uses a **Subnet Mask**. 

The subnet mask acts as a literal filter. Wherever there is a `255`, that part of the address is locked to the **Network**. Wherever there is a `0`, that part is assigned to the **Host**.

### The Default /24 Mask (Most Common)
Look at what happens when we apply a standard `255.255.255.0` mask to a home IP address:

    IP ADDRESS   :  192  .  168  .   1   .   50
    SUBNET MASK  :  255  .  255  .  255  .   0
                   -----------------------------
    RESULT       : [--- NETWORK ID ----]   [HOST]

*   **Network ID:** `192.168.1.0` (The neighborhood)
*   **Host ID:** `.50` (Your specific PC)
*   **Capacity:** Because you only have one octet (a `0`) left for hosts, this network can only hold **254** usable devices.

### CIDR Notation (The Slash)
Writing out `255.255.255.0` is tedious, so network engineers use **CIDR (Classless Inter-Domain Routing) Notation**. They just count the number of binary `1`s in the mask.

*   `255.0.0.0` = **/8** (Massive network, 16 million hosts)
*   `255.255.0.0` = **/16** (Medium network, 65,000 hosts)
*   `255.255.255.0` = **/24** (Small network, 254 hosts)

<br>

## 4. Why Do We Subnet?

Enterprise engineers don't just use default masks; they "borrow" bits to chop large networks into smaller, more efficient pieces (Subnetting).
1.  **Security:** Isolating the HR department's network from the Guest Wi-Fi.
2.  **Performance (Broadcast Domains):** If 5,000 computers are on the same subnet, their background chatter (broadcasts) will cripple the network. Subnetting breaks them into smaller, quiet rooms.
3.  **Organization:** Mapping IP schemes to physical building floors (e.g., Subnet 10 is Floor 1; Subnet 20 is Floor 2).
